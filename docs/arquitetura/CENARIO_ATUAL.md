# Cenário Atual - Med SOS

## 1. Visão Geral
Este documento descreve o estado atual do projeto *Med SOS*. O sistema está em fase de prototipagem, com foco na otimização do fluxo de atendimento de emergência, garantindo agilidade e segurança desde a concepção.

## 2. Fluxo de Usuário (Protótipo)
O protótipo atual concentra-se na redução de atrito durante o cadastro de emergência. O fluxo compreende:
*   **Identificação:** Coleta rápida de dados básicos de saúde.
*   **Envio de Alerta:** Disparo da notificação para unidades de saúde integradas.
*   **Interface:** Design simplificado (UX) focado em dispositivos móveis para cenários de alta pressão.

## 3. Considerações de Segurança (Fase Inicial)
*   **Conformidade:** Arquitetura alinhada às diretrizes da LGPD para proteção de dados sensíveis.
*   **Roadmap de Segurança:** Estabelecimento de base para implementação futura de:
    *   Controle de acesso rigoroso.
    *   Criptografia de dados em repouso.
    *   Trilhas de auditoria (logs) para rastreabilidade.
