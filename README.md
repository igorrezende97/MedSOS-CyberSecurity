# Med SOS - Sistema de Segurança e Resiliência em Saúde

## Sobre o Projeto
O **Med SOS** é um projeto integrador (PI2) voltado para a criação de uma solução de saúde digital, com foco em *Security by Design*. O objetivo central é demonstrar a implementação prática de controles de segurança cibernética (baseados no framework CIS Controls) em aplicações de saúde pública, garantindo a integridade, confidencialidade e disponibilidade dos dados sensíveis dos usuários.

## Status do Projeto
🚧 **Em desenvolvimento** (Fase de estruturação e definição de requisitos de segurança).

## Objetivos
- [ ] Implementar controles de inventário de ativos e softwares (CIS Controls 1-6).
- [ ] Desenvolver arquitetura com foco em proteção de dados e criptografia.
- [ ] Aplicar princípios de UX para um fluxo de navegação seguro e intuitivo.
- [ ] Validar a eficácia dos controles de segurança com base em metodologias de auditoria técnica.

## Roadmap de Segurança
Este projeto seguirá o rigor técnico aprendido através das certificações de segurança cibernética, buscando alinhar a experiência do usuário (UX) à segurança da informação.

## Por que este projeto?
O *Med SOS* nasce da necessidade de conciliar a **agilidade no atendimento de saúde** com a **rigidez necessária na proteção de dados (LGPD)**. Este repositório servirá como um laboratório de implementação de controles de cibersegurança, onde cada funcionalidade será documentada com base em:
1. **Segurança por design** (prevenção antes da falha).
2. **Análise de dados** (para melhoria contínua da experiência do usuário).
3. **Auditabilidade** (logs e rastreabilidade conforme frameworks de mercado).
